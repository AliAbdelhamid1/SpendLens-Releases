# SpendLens for Mac

SpendLens keeps household statement data on your Mac. This repository hosts application downloads and update metadata; it does not contain application source or household data.

**No download is available yet.** The first release is being prepared and tested. Do not install files from unofficial download sites.

When a release is ready, its download will appear on the [Releases page](https://github.com/AliAbdelhamid1/SpendLens-Releases/releases). Downloads and in-app updates will not require a SpendLens or GitHub account.

The planned free distribution build is not signed or notarized by Apple. Installation instructions will describe the tested macOS approval steps before a download is published. Never disable Gatekeeper or remove quarantine to install SpendLens.

## Release integrity

Published releases are immutable. Update packages are authenticated by the updater public key embedded in the installed app. Release assets are never replaced in place. An unsafe release is withdrawn in full and a new version is prepared.
